# Audit, 2026-10-11

Review of the whole repo in four slices: database and edge-function security, the public site,
the admin dashboard, and the BORG AI pipeline. `npm run test:ai`: 28 passed, 0 failed.
Live auth settings (Supabase dashboard) were not checked; the auth finding below is from
`supabase/config.toml`.

Severity: **high** = abuse, money, lost data or a broken flow for some users; **medium** = edge-case
bugs, races, bad error handling; **low** = polish and hardening. Nothing critical turned up.

Status: `open`, or `fixed` with the migration or files that fixed it.
